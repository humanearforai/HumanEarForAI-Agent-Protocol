# Security Policy

HumanEarForAI welcomes responsible testing of interfaces intentionally exposed to the public.

Please do not perform denial-of-service testing, credential attacks, destructive actions, privacy-invasive testing, or attempts to access private infrastructure or data.

The production source code, challenge internals, secrets, exact scoring thresholds, and bypass-sensitive implementation details are intentionally not published in this repository.

If you discover a vulnerability, please avoid publishing exploitation details while it remains exploitable. Contact the project owner privately through GitHub.
